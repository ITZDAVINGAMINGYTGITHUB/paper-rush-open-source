# Contributing to Paper Rush

Thanks for helping improve Paper Rush.

## Before opening a pull request

1. Keep changes focused and explain what player-facing or developer-facing problem they solve.
2. Do not commit `.env` files, API secrets, session tokens, database exports, private user data, or production-only credentials.
3. Do not add music, artwork, fonts, or other third-party assets unless their redistribution rights are clear.
4. Run the relevant tests and verify gameplay changes locally before submitting.

## Bug reports

Include reproduction steps, expected behavior, actual behavior, browser/device information, and screenshots or recordings when useful.

## Security issues

Do not publish sensitive vulnerabilities in a public issue. Follow `SECURITY.md` instead.
